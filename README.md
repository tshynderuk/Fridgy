# 🥑 Fridgy — Your Kitchen Has a Brain

Fridgy is an AI-powered Android cooking assistant designed to help users decide what to cook using ingredients they already have.

## 🎯 Project Goal
Make everyday cooking easier, reduce food waste, and help users save time and money.

## ✨ Planned Features
- Fridgy NOW — personalized recipe recommendations
- Fridgy Rescue — recipes that prioritize ingredients needing attention
- Fridgy Loop — smart inventory of available ingredients
- AI ingredient recognition using the camera
- Step-by-step cooking instructions
- Recipe history and favorites

## 🛠 Technology Stack
- Kotlin
- Jetpack Compose
- Android Studio
- Python + FastAPI (planned)
- AI API (planned)
- Room Database (planned)

## 🚀 Current Status — Lab 1
The Android application has been created and tested on a Pixel 7 emulator (Android 15, API 35).

Implemented:
- Initial Fridgy user interface
- Demo ingredient list
- Interactive button showing a sample recipe

The current recipe is a predefined demonstration. AI recommendations and backend integration will be implemented in future labs.

## ▶️ Getting Started
1. Clone the repository.
2. Open the project in Android Studio.
3. Wait for Gradle Sync.
4. Run the app on an Android emulator or device.
